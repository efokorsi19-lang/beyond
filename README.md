# Isaac's Graduation Invitation

This folder is ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository named `alavi-graduation`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings** → **Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`. Save.
4. GitHub will show the public invitation address, usually `https://YOUR-USERNAME.github.io/alavi-graduation/`.

## RSVP responses and images

GitHub Pages provides free static hosting but does not collect form responses itself. `formspree-config.js` is ready for a Formspree endpoint if you later choose that service. Its free tier does not offer image uploads, so the photo fields need a paid Formspree plan or a different upload service.

Until a response service is connected, RSVPs and wishes are saved only in the visitor’s browser. For a fully free image-upload route, use a Google Form upload form; guests will need to sign in to Google to attach pictures.
